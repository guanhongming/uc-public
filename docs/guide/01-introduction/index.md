### Overview & Purpose

This document provides a comprehensive technical overview of the Uni Application platform, a specialized web application designed to streamline and centralize the university application process for students, teachers, and administrators at RCF. The application is built with Laravel backend and a dynamic Vue.js, Inertia.js frontend.

The primary purpose of this application is to serve as a "one-stop shop" for students to compile and manage their university application materials. Students can fill out detailed forms covering everything from target universities and academic scores to standardized tests and extracurricular activities similar to the actual UCAS system.

For teachers and counselors, the platform provides a dashboard to monitor the progress of their and **only their** students, view their application details, and filter them by name, year, or academic class. This enables educators to provide targeted support and guidance throughout the application journey. The admin role has overarching access to manage the platform's users and data. 

This documentation will guide developers through the system architecture, local development setup, and key features, enabling them to contribute effectively to the project.
